# Cryo-Bed-Topography-MCMC
UF course GlY 4930: Geophysical Exploration of the Cryosphere ~ Using Monte Carlo Markov Chain to simulate realistic bed topography
Tutorial (T1, T2, T3, T4) codes provided by Niya Shao and modified for Thwaites Region
T1 - Loading in Thwaites information from DEMOGORGN data
T2 - Sequential Gaussian simulation as provided by https://gatorglaciology.github.io/gstatsimbook/4_Sequential_Gaussian_Simulation.html
T3 - Large Chain MCMC Chain
T4 - Small Chain MCMC Chain
